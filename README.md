# radar-vc-data

Données du Radar VC Europe (santé, robotique, défense) : startups européennes notées sur 100 avec la grille d'IC.

- `targets.json` : une startup par ligne (score, sous-scores, levée, équipe, traction, contacts, sources).
- `meta.json` : date de la dernière mise à jour, nouveautés de la semaine.

Mis à jour automatiquement par Claude. Lu par l'application Lovable via
`https://raw.githubusercontent.com/smadjulia-source/radar-vc-data/main/`.
